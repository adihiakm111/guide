User Manual – Snake Game

Yahaan Auto aur Manual modes dono ka description diya hai.

Manual Mode Controls

  • Up Arrow – Move Up
  • Down Arrow – Move Down
  • Left Arrow – Move Left
  • Right Arrow – Move Right

Rules

  • Wall hit = Game Over
  • Body hit = Game Over
  • Food eat = Score Increase

Troubleshooting

  • Game load na ho → Refresh
  • Lag ho → Browser cache clear karo
